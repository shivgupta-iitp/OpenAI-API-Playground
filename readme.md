# OpenAI API Playground

A hands-on Python project exploring the OpenAI API and its
applications in text generation, AI assistants, email
summarization, image understanding, and image generation.

## Features

- Text generation using the OpenAI API
- Prompt engineering and instruction-based responses
- AI personal assistant for answering questions
- Email summarization
- Image understanding using visual inputs
- AI image generation
- AI image editing

## Tech Stack

- Python
- Jupyter Notebook
- OpenAI API
- OpenAI Python SDK
- Base64 image encoding

## Project Structure

OpenAI-API-Playground/
├── openai_api.ipynb
├── requirements.txt
├── .env.example
└── README.md

## Installation

1. Clone the repository:

2. Navigate to the project directory:

   cd OpenAI-API-Playground

3. Install the dependencies:

   pip install -r requirements.txt

4. Configure your OpenAI API key as an environment variable.

5. Open the notebook:

   jupyter notebook openai_api.ipynb

## API Configuration

Set your API key in an environment variable named OPENAI_API_KEY.

Never upload your actual API key to GitHub.
